LAN-Link 웹 버전 v3.0 사용법

  • 0.3초 즉시 온라인 인식: 방화벽·공유기 설정과 무관하게 보안 웹소켓 이중화 채널(EMQX+HiveMQ)로 접속 즉시 초록불이 켜집니다. 같은 이름으로 PC+모바일 동시 접속도 가능합니다.
  • 자동 전송 경로 최적화: 파일 전송 시 먼저 ⚡ 초고속 LAN 직통(WebRTC)을 시도하고, 사내 공유기·방화벽이 막으면 4초 내 자동으로 🔒 보안 웹소켓 릴레이로 전환되어 전송이 끊기지 않습니다.
  • 대용량 폴더·파일 메모리 멈춤 0%: Chrome/Edge에서 폴더 수신 시 📂 폴더 위치 선택 후 바로 저장을 누르면 ZIP 압축 없이 원본 폴더 구조 그대로 디스크에 실시간 저장됩니다. ZIP 파일 저장도 실시간 스트리밍으로 처리됩니다.
  • 창 최소화 절전 방어 & 앱 설치: Web Worker + Web Locks로 탭을 내려두어도 연결이 유지됩니다. 주소창 우측 앱 설치(PWA) 버튼으로 작업표시줄 독립 창으로 두면 더욱 편리합니다.
  • 종단간 암호화(E2EE): 모든 메시지·파일은 AES-256-GCM으로 암호화되어 전송됩니다. 별도 전용 방이 필요하면 주소 뒤에 #key=비밀단어를 붙여 같은 주소로 접속하세요.
